# BRIEF — 短尺ニュース

上にスワイプして次へ進む、縦型短尺ニュースアプリ（PWA対応）。

## 起動

```bash
npm install
npm run dev
```

## スマホにインストール

本番: https://shortnews-theta.vercel.app

- **Android / Chrome** … 画面下部の「追加」、またはブラウザメニューの「アプリをインストール」
- **iPhone / Safari** … 共有ボタン → 「ホーム画面に追加」

## 操作

- **上スワイプ / スクロール** … 次のニュース
- **画面タップ** … 再生 / 一時停止
- **ジャンル選択 / 設定** … 興味ジャンルの追加・削除
- **キーボード** … `↑` `↓` で移動、`Space` で一時停止

## ブランドアセット

- `public/brand/brief-icon-master.png` … アプリアイコン原版
- `public/brand/brief-splash.png` … スプラッシュ
- `public/icons/` … 各サイズの PNG アイコン
